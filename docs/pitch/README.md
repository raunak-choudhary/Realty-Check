# Pitch

Pitch material for Realty Check from HackPrinceton Fall 2026.

- `talk_track.md` is the two-minute talk track used for the video and the live demo.
- `deck/` is the source of the seven-slide deck. Each slide in `deck/slides/` is an HTML fragment (one `<section>` with presenter notes in an `<aside>`). All slides share the styles in `deck/deck.css`, and `deck/deck.json` sets their order. No slide viewer is included.
- `architecture.html` is the interactive system architecture diagram. Open it in a browser. The still version is `docs/img/system-architecture.png`.

Slides in presentation order

1. `cover.html` shows the title and team
2. `hook.html` covers how everyone books today
3. `expect.html` contrasts the listing with the record
4. `nobody.html` says nobody checks the listing
5. `onfile.html` shows the four record sources
6. `demo.html` is the live demo cue
7. `close.html` covers what comes next
