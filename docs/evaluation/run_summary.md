## How to read these numbers

Many runs were repeats of the same pages while the product was being tuned, so the totals are not an accuracy figure. "Cannot check" means no source covered the claim. Absence of evidence is never counted as a mismatch, so a claim with nothing to compare against lands in "cannot check", not in "does not match".
