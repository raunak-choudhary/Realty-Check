How confidence works
  1. Only shown when a claim doesn't match or is close.
  2. Score 0–100. High is 75 and up, medium 45 and up.
  3. A source measuring this home counts more than one about the floor plan or the building.
  4. The deciding source is the one that weighed most; others are listed under it.

D · Cut list

What goes

  • Claim field as hero visual (report)shrinkThe table now says the same with words. Keep it as the drawer's small progress strip.
  • Dark "Four sources. One address." bandshrinkRenters don't choose sources. One line each, at the end.
  • "Biggest difference" line under the heroremoveIt repeats the first mismatch, which now sits right below.
  • Rent, Rules, Schools topics in Fill me incollapseUseful, but not about the claims. One "More about the area" fold.
  • Building class, CoStar rating, LEED, elevators count, parcel numberremoveInvestor facts. They don't change the decision to rent this home.
  • Owner and manager namesremoveOwner type (company or individual) is enough, and safer.
  • Floor plans drawn to scale stripcollapseKeep only this home's plan, next to the size mismatch.
  • Match cards with picturescollapseOne line each. Pictures only where there is a 3D jump.
  • Separate "Couldn't check" band with reasonscollapseFolded into the matches list as greyed lines.
  • "Ask before you tour" sectioncollapseMoved onto each mismatch as "Copy as a question".
